Portanto não há cegamento cognitivo; há isolamento verificável de entradas e etapas: dispositivo usa apenas fonte constitucional; evidência usa apenas fontes da obra; rótulos não entram no compilador. Congelamentos registram hashes antes de cada comparação humana.

Dados e código novos devem permanecer exclusivamente nesta árvore. Usar Python com `-B` para evitar escrever caches nas baselines. Sem firmware, IDX, SD, novo catálogo oficial ou alterações silenciosas.
